# 酒店加床管理系统

按**房型消防核准人数**与**房间折叠床位空间**受理加床申请，覆盖床架/布草库存占用、
配送派单并发认领、住客确认计跨夜房费、跨夜续住、提前撤床、退房逐件回收与缺件/损坏结算。
仅依赖 Python 3.11 标准库，SQLite 存资源占用，验收照片存本地，房账由模拟适配器返回。

## 一条命令启动

```bash
python3 run.py --reset
```

启动后打开 <http://127.0.0.1:8000/>。启动日志会先演示一次**超员样例**
（801 标准间已住满 2 人，再申请加床被拒绝：`入住人数超限：核准 2 人，叠加后将达 3 人`）。

参数：

| 参数 | 说明 |
|---|---|
| `--reset` | 清空并重建演示数据（含一条已驳回的超员申请） |
| `--port 9000` | 更换端口（默认 8000） |
| `--host 0.0.0.0` | 允许局域网访问 |

运行数据位于 `data/hotel.db`（SQLite）与 `data/photos/`（验收照片）。

## 三个页面

- **房态总览**（`/`）：房间卡片直接显示**已加床数量**、在住人数/消防核准、剩余床位、
  超员红色告警；可提交申请、前台改价（原报价留痕）、派单、驳回、跨夜续住；下方看床具库存。
- **配送派单**（`/delivery.html`）：按**床架 / 被褥 / 枕头分项核对**，发现床架损坏可
  当场隔离并自动改配好件（不向客人收费）；认领配送单、登记送达（可传验收照）、请住客确认、提前撤床。
- **退房结算**（`/checkout.html`）：**借出与回收逐件对照**，每件选完好/损坏/缺失并必填原因，
  实时汇总赔偿金额；漏检任意一件无法结算；历史单据看房账流水、免除审批与回收照片。

配色：酒店白 + 深绿 + 温和金色；金额使用等宽数字，缺件原因在表格中清楚可读。

## 业务规则

| 场景 | 处理 |
|---|---|
| 入住人数超限 | 叠加已有加床后超过房型消防核准人数 → 拒绝（`OVER_OCCUPANCY`） |
| 房间空间不足 | 折叠床数超过房型床位数 → 拒绝（`NO_SPACE`） |
| 床架损坏（配送前） | 坏件隔离为 `damaged` 不再分配；从库存自动改配，不收费 |
| 跨夜续住 | 延长退房日，新增夜晚按**确认时锁定的原报价**补收 |
| 提前撤床 | 未使用夜晚按原报价退还，另收 ￥50 上门服务费 |
| 退房漏收布草 | 借出物未逐件核对 → 拒绝结算（`ITEMS_UNCHECKED`） |
| 缺件 / 损坏 | 必填原因；分别按重置价/维修价赔偿并计入房账，缺件资产报废 |
| 床架分配不可重叠 | 每件库存行用条件 `UPDATE ... WHERE status='available'` 原子占用 |
| 双认领竞争 | `UPDATE deliveries SET claimed ... WHERE status='pending'`，并发只有一次 rowcount=1 |
| 房务员免责 | 返回 403；仅前台可免除损坏/缺件费用，冲账记录留痕 |
| 前台调价保留原报价 | `quote_adjustments` 表记录每次 `from → to` 与操作人 |

计价（单位：分）：跨夜费 = 每床每晚报价 × 床数 × 晚数（退房当天不计）；
损坏 床架￥800 / 被褥￥200 / 枕头￥80；缺件 床架￥1200 / 被褥￥300 / 枕头￥120。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖 24 个用例：

- **容量限制**：超消防、叠加已有加床超限、空间先于人数超限、非法输入；
- **库存竞争**：床架顺序/并发分配不重叠、库存不足整单回滚（床架不被半单锁住）、
  三名房务员并发认领同一配送单只有一人成功；
- **跨夜费用**：确认计晚、多床多晚、0 晚拒绝、续住按锁定价、改价留痕与权限、
  提前撤床退款 + 上门费；
- **缺件结算**：全完好、缺被褥赔偿与资产报废、床架损坏隔离、原因必填、
  漏收拦截、房务员不能免责/前台免责冲账、配送前坏件改配免费；
- 另有真实 HTTP 端到端用例（含照片上传/取回与并发双认领）。

## 目录结构

```
hotel_beds/
  db.py          SQLite 表结构与连接（WAL、外键、busy_timeout）
  service.py     核心领域服务（所有写操作 BEGIN IMMEDIATE 事务）
  billing.py     房账模拟适配器（写 ledger_entries，返回 BILL-xxxxxx 凭证）
  photos.py      验收照片本地存储（防目录穿越）
  pricing.py     跨夜/损坏/缺件/提前撤床计价
  seed.py        房型规则、库存、房间与超员样例
  server.py      标准库 ThreadingHTTPServer：JSON API + 静态页 + 照片
web/             三个页面 + 样式（酒店白/深绿/温和金）
tests/           unittest 测试
run.py           一键启动
```

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/requests` | 前台提交加床申请（校验消防人数/空间） |
| POST | `/api/requests/{id}/quote` | 前台改价（`role=front_desk`，原报价留痕） |
| POST | `/api/requests/{id}/assign` | 原子锁定床架+布草，生成配送单 |
| POST | `/api/deliveries/{id}/claim` | 房务员认领（并发只成功一次） |
| POST | `/api/deliveries/{id}/replace-item` | 配送前坏件隔离 + 自动改配 |
| POST | `/api/deliveries/{id}/delivered` | 登记送达 |
| POST | `/api/deliveries/{id}/photos` | 上传验收照片（base64，存本地） |
| POST | `/api/deliveries/{id}/confirm` | 住客确认 → 跨夜费入房账 |
| POST | `/api/requests/{id}/extend` | 跨夜续住（按锁定原报价补收） |
| POST | `/api/deliveries/{id}/early-remove` | 提前撤床（退未使用晚 + 上门费） |
| POST | `/api/deliveries/{id}/recover` | 退房逐件回收结算（缺件/损坏入账） |
| POST | `/api/ledger/waive` | 前台审批免除赔偿（房务员 403） |
| GET | `/api/rooms` / `/api/inventory` / `/api/deliveries/{id}` / `/api/rooms/{no}/billing` | 查询 |
